# REGAIN — Product Overview

## What It Is

REGAIN is an AI-powered reskilling platform that runs personalized campaigns for professionals in career transition. It combines military-style transition structure with real-time market intelligence to deliver adaptive, evidence-based career development.

## Who It's For

Three primary personas:

1. **Veterans** transitioning to civilian careers (~200,000/year). Have structured backgrounds but face identity translation challenges.
2. **AI-displaced workers** whose roles were automated or restructured. Skilled professionals who need to pivot but lack direction.
3. **Career pivoters** making voluntary transitions. Need to document transferable skills and build toward a new trajectory.

## Core Pillars

1. **Daily Missions** — Small, completable skill-building tasks calibrated to the user's campaign phase. Early missions are quick wins. They escalate as momentum builds.
2. **Evidence Vault** — Every completed mission logs tagged skills, timestamps, reflections, and artifacts. This becomes a living portfolio of documented growth.
3. **Adaptive Coaching** — An AI agent that monitors patterns, adjusts difficulty, flags avoidance, and conducts periodic check-ins. Uses episodic memory to improve over time.
4. **Market Intelligence** — An AI agent that scans job trends, maps skills to demand, and aligns missions to real market opportunities. Provides 360-degree awareness.

## Product Philosophy

- Tech and agent forward. Let brilliant solutions make problems self-evident. Never lead with the problem.
- Evidence over affirmation. Every encouraging word ties back to documented proof.
- Structure that adapts. Not rigid programs — intelligent campaigns that respond to the user and the market.

## User Journey

Onboarding → Transition Profile generated → Campaign Roadmap created → Daily Missions begin → Evidence accumulates → Coaching adapts → Market alignment grows → User has documented track record + measurable progress toward next role.
